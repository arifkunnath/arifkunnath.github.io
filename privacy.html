Privacy Policy

Last updated: 11 October 2026

This policy covers PixelToons Uploader, a private tool that the owner of the PixelToons YouTube channel uses to upload the channel's own videos, and this website.

Who uses the tool

Only the channel owner. The tool is not available to the public and never asks anyone else to sign in.

Viewers and children

PixelToons videos are made for children and marked Made for Kids on YouTube. The tool and this website collect no information from viewers, including children: no names, emails, comments, accounts, cookies, analytics or tracking.

YouTube API Services

PixelToons Uploader uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's use of data is described in the Google Privacy Policy.

Google and YouTube data

  • The tool uses the YouTube Data API with one permission, youtube.upload, which lets it upload videos to the owner's own channel. It cannot read, edit or delete videos, read comments, or access any other account.
  • The only Google data it keeps is the owner's OAuth refresh token, stored encrypted as a private GitHub Actions secret, used only to upload the owner's videos.
  • It does not sell, share or transfer any Google user data to anyone.
  • The video file is downloaded only for the moment of upload and is not kept by the tool afterwards.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, or on request, the stored refresh token is deleted from the GitHub secrets within 7 days. No other YouTube or Google data is stored, so there is nothing else to delete.

This website

This site is a static page hosted on GitHub Pages. It sets no cookies and runs no analytics. GitHub may log visits for security; see the GitHub Privacy Statement.

Changes and contact

Changes to this policy are posted on this page. Questions: contact the channel owner through the PixelToons channel page.
