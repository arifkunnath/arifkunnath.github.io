Excellence Awards Portal

An administration portal for the university's excellence awards. Admins build an award from categories, each with its own eligibility, prizes, application form, scoring rubric and review workflow, then publish a public application link.

Overview

What it does

  • Six-step category editor: details, eligibility, prizes, workflow, form and rubric.
  • Form builder with drag-and-drop fields, file uploads with limits, declarations and a live bilingual preview, validated on the server.
  • Rubric library: criteria and sub-criteria with weights and rating bands; each category gets its own copy to adjust.
  • Five workflow stages, each switchable, with people picked from the HR directory.
  • Publishing rules: an award needs dates and an active category; status (draft, scheduled, open, closed) is computed.
  • Careful database migrations that move data first, then drop old columns.
