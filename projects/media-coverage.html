Media Coverage Portal

A sibling of the Marketing portal for the university Media Center. Staff request news and photo/video coverage of events; an approver signs off, then the Editing & Publishing and Multimedia sections work in parallel.

Overview

What it does

  • True RTL/LTR switch at runtime, with every string in one table and a build that fails if any Arabic translation is missing.
  • Journey rail on every request shows where it stands across both parallel section lanes.
  • "Your action now" strip shows only the actions the server allows for this user and status.
  • Accessible by design: states always carry an icon and words, never colour alone.
  • Notifications are queued and logged, with editable bilingual email templates.
