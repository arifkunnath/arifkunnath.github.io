UOSApi

An ASP.NET Core Web API that gives the mobile app one controlled doorway into several back-end systems: student records in Oracle, asset custody in SQL Server, the library platform, and configurable service links.

Overview

What it does

  • One API, many sources: Oracle views, a SQL Server stored procedure, an external library API and JSON configuration.
  • Defence in depth: token validation, 60 requests/minute per IP, security headers, HTTPS/HSTS and no-store caching.
  • Traceable: every request carries a correlation ID, and errors return a generic message with that ID instead of internals.
  • Secrets out of source: connection strings and keys come from environment configuration on the server.
  • Public endpoints (quick links) work without a token; everything else needs one.
